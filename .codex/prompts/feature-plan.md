# FEATURE IMPLEMENTATION PLAN

Feature ID:

{{FEATURE_ID}}

Read the verified requirement, current-system analysis, impact analysis, and
approved solution design. Write:

docs/features/{{FEATURE_ID}}/05-implementation-plan.md

Break work into independently verifiable tasks. For every task specify its
repository, files or symbols, behavior change, dependencies, compatibility
constraints, tests, observability, rollback, and completion evidence. Define
cross-repository delivery order and explicit out-of-scope work.

Do not modify production code. Stop after producing the plan and identify the
decisions that require human approval before implementation.
