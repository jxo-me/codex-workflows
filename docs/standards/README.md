# Engineering Standards

Status: NOT_INITIALIZED

These documents record conventions discovered from the target Workspace. They
are not a generic style guide and must not be filled from preference alone.

Classify observations as:

- CURRENT_STANDARD: dominant, successful pattern
- LEGACY_PATTERN: retained for compatibility but not preferred for new work
- INCONSISTENT_PATTERN: competing patterns with no verified standard
- RISKY_PATTERN: pattern with evidence of correctness or operational risk

Every concrete rule should cite representative code, tests, configuration, or
deployment evidence. Use UNKNOWN and NEEDS_VERIFICATION where evidence is
insufficient.
